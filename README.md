# Task-1-
## Foundation & Environment SetupInternship: ApexPlanet Software Pvt. Ltd. — Cybersecurity & Ethical Hacking Internship Timeline: Days 1–12 Objective: Build strong fundamentals in cybersecurity, networking, and cryptography, and set up a professional hacking lab for hands-on practice.

## 1. Cybersecurity Basics
- CIA Triad: Studied Confidentiality, Integrity, and Availability as the core principles behind any security decision.
- Threat Types: Explored Phishing, Malware, DDoS, SQL Injection, Brute Force, and Ransomware, and how each one actually operates.
- Attack Vectors: Covered Social Engineering, Wireless Attacks, and Insider Threats as the main ways attackers gain entry.
## 2. Lab Environment Setup
- Hypervisor: VirtualBox
- Attacker Machine: Kali Linux
- Target Machines: Metasploitable2 and DVWA (Damn Vulnerable Web App)
- Network Configuration: Host-Only Adapter, so the attacker and target VMs can talk to each other in an isolated lab network
## 3. Linux & Networking Fundamentals
- Navigation & Permissions: Practiced pwd, ls, cd, chmod, and chown for file system navigation and access control.
- Package Management: Used apt and dpkg to install and manage tools.
- Networking Commands: Verified connectivity and diagnosed the network using ifconfig, ping, netstat, and traceroute.
- OSI Model & TCP/IP: Reviewed the OSI layers, the TCP/IP suite, DNS, HTTP/HTTPS, and IP addressing & subnetting.
## 4. Cryptography Basics
- Symmetric vs Asymmetric Encryption: Compared how each approach handles keys and use cases.
- Hashing: Studied MD5 and SHA-256 and why hashing differs from encryption.
- Hands-on with OpenSSL: Encrypted and decrypted sample messages from the command line to see the concepts in practice.
## 5. Tool Familiarization
- Wireshark: Captured and inspected live packet traffic on the lab network.
- Nmap: Ran scans against the target VM to identify open ports and services.
- Burp Suite: Set up the proxy, intercepted requests, and explored the HTTP history and Repeater tabs.
- Netcat: Used for basic network debugging and connectivity tests.
